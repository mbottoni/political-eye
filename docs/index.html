Regras da casa

  • Só dados oficiais, com a fonte em cada número.
  • Nenhum CPF completo é publicado.
  • Pessoas punidas são contadas, nunca nomeadas.
  • Cada regra e problema dos dados está na metodologia.
Metodologia

Como funciona

Um projeto de "git scraping": os dados vivem no próprio repositório, versionados.

Coleta

Jobs agendados no GitHub Actions baixam cada fonte oficial: as APIs da Câmara e do Senado, o TSE, o Portal da Transparência, o Tesouro Nacional e o PNCP.

Tabelas

Cada execução refaz tabelas CSV ordenadas e só faz commit quando algo mudou, então o histórico do git registra o que mudou e quando.

Painéis

Os painéis leem essas tabelas direto do repositório, no seu navegador. Os números desta página são lidos agora e mudam quando chegam dados novos.
